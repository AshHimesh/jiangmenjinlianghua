# 江门金量化 · 开发日志规范

> 版本：v1.0 ｜ 更新日期：2026-09-10

## 1. 位置与命名
- **文件夹**：`开发日志/`
- **文件命名**：`YYYY-MM-DD.md`（例：`2026-09-10.md`）
- **模板文件**：`开发日志/_模板.md`（不要改动、不要当作当天日志）

## 2. 自动记录机制
- 每天首次开发前，运行 `python tools/daily_log.py`，脚本会自动创建当天日志（已存在则跳过，不会覆盖）。
- 每天开发结束时，**更新当天日志**：在「已完成」勾选做完的事，在「待办」写下下一步。

## 3. 日志结构
每篇日志固定三块：
- **✅ 已完成**：今天做完的事项。
- **📋 待办**：下一步要做的事项。
- **备注**（可选）：遇到的问题、关键决策、依赖项。

## 4. 记录规则
1. 每完成一个子任务，立即在「已完成」打勾记录，不积压到一天结束。
2. 「待办」始终指向**当前阶段下一个未完成的子任务**（参照 `docs/04-开发执行步骤.md`）。
3. 阶段完成、需求/技术变更等重大事件，写入「备注」。
4. 日志只记事实与进度，不写代码。
