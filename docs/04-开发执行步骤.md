# 江门金量化 · 开发执行步骤

> 版本：v1.0 ｜ 更新日期：2026-09-10

## 推进原则（最重要）
- **一次只做一个阶段**，绝不提前做下一阶段的功能。
- 每个阶段**可独立运行、可验收**，验收通过后再进入下一阶段。
- 每阶段结束，更新开发日志并同步本文件的勾选状态。

# 第二阶段规划（阶段 7-9）

> 需求详见 `docs/01-项目需求说明.md` 第 5 章。以下为执行细则。
> 进度：阶段 7（金十 MCP）、阶段 8（品种扩充）、阶段 9（分析报告与图表）已完成并验收。

## 阶段 7：金十 MCP 接入
**任务**
1. 新增 `src/mcp.py`：标准 MCP 客户端
   （`initialize` → `notifications/initialized` → `tools/list` / `resources/list` → `tools/call`；
   处理 SSE 响应、`Mcp-Session-Id`、`structuredContent`、`cursor` 分页、JSON-RPC 错误）。
2. 把 8 个金十工具接入 `src/tools.py`，供 AI 按需调用。
3. 读取 `quote://codes` 资源，确认金十支持的完整品种清单。
4. ⚙ 设置面板新增金十配置：**用户自行填写 API Key** + 启停开关 + 连接自检按钮。
5. 界面与报告中对金十来源数据**明确标注**（来源标签/角标）。
6. **额度保护**：工具层加调用计数，接近 1500/天时给出提示；绝不进入刷新循环。
7. `--selftest` 增加 MCP 连通性检查项。

**验收标准**：
- 用户填入自己的金十 Key 后，AI 能查询快讯、资讯、财经日历；
- 界面上能一眼区分哪些数据来自金十；
- 未配置 Key 时金十功能优雅禁用，不影响其它功能；
- 额度耗尽时给出可读提示而非报错崩溃。

**验收结论**：✅ 通过（2026-09-18）
- 离线自测 **55 项通过 / 0 失败**；真连金十 **72 项通过 / 0 失败**，8 个工具全部实测可用
- `--selftest`：14 / 14 行情正常，未配 Key 时金十项跳过且不影响其它功能
- 本阶段决定：**R7-E（金十兜底行情）不实现** —— 行情看板价格恒来自免费源，
  金十只走 AI 按需调用，避免 2 秒刷新打爆额度
- 开发期凭据：联调 token 不得写进任何入库文件。`tools/check_jin10_mcp.py` 与
  `tools/test_stage7.py` 均从环境变量 `JIN10_DEV_TOKEN` 或本地未跟踪文件
  `tools/_jin10_token.txt` 读取（`tools/_*` 已在 `.gitignore` 中）

1. 新增「上海金 Au99.99」（浙商积存金定价基准）。
2. 第一批（🥇 6 个）：沪金 AU、沪银 AG、沪深300、创业板指、恒生指数、美元兑离岸人民币。

## 阶段 9：分析报告与图表
**任务**
1. 每条 AI 回答增加**复制**能力。
2. 新增**导出报告**：写入 `reports/` 目录，文件名含品种与时间。
3. 报告头部自动附元信息（时间、品种、数据时间戳、当前价、启用的 skill、数据来源）。
4. 新增 AI 工具 `render_analysis_chart`：接收结构化的
   `symbol / period / waves / support / resistance / entry / stop_loss / take_profit`，
   用 matplotlib 绘制K线并标注**浪型、支撑压力位、止盈止损位**，输出 PNG。
5. 报告内嵌该图表；图表**只出现在报告里**，主界面保持极简。
6. 处理 matplotlib 中文字体（Windows 用微软雅黑，缺失时回退）。

**验收标准**：
- 生成的报告可直接复制/导出；
- 报告里的图表能看清K线、浪型标注、支撑压力线、止盈止损线；
- 主界面依然不显示K线。

**验收结论**：✅ 通过（2026-09-18）
- `tools/test_stage9.py`：**36 项通过 / 0 失败**（工具注册 / 出图 / 元信息 / 自包含 HTML / 文件安全）
- `--selftest` 新增图表检查：中文字体 msyh.ttc 可用，带完整标注出图成功（自检图片用完即删）
- 回归：`test_stage7.py` 55 项通过（工具数 3→4、11→12 已同步更新）
- 导出格式采纳「两种都出」（.md 可编辑 + .html 自包含可打印）；图表周期由 AI 选主周期；
  「一键生成完整研报」已实现（固定指令 + 强制出图）
- 三个原待确认项已在 docs/01 5.3.3 写明结论
