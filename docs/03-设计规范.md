# 江门金量化 · 设计规范

> 版本：v1.0 ｜ 更新日期：2026-09-10

## 1. 设计原则
- **极简、白色、留白充足**，去掉一切多余装饰。
- 信息优先级：**价格 > 品种 > 对话**。
- 不追求花哨动效，只求清晰、安静、耐看。

## 2. 配色

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面背景 | `#FFFFFF` | 纯白 |
| 分区/卡片背景 | `#F7F8FA` | 极浅灰 |
| 主文字 | `#1A1A1A` | 近黑 |
| 次文字 | `#8A8A8A` | 中灰 |
| 边框/分隔线 | `#EBEBEB` | 浅灰 |
| 上涨 | `#E03131` | 红 |
| 下跌 | `#12B886` | 绿 |
| 主按钮 | `#1A1A1A` | 黑色按钮白字 |
| 选中高亮 | `#F0F1F3` | 选中态背景 |

## 3. 字体
- 全局：系统默认字体栈（Segoe UI / 微软雅黑）。
- **数字统一等宽**（`font-variant-numeric: tabular-nums`），避免刷新时数字跳动。

## 4. 布局

```
┌──────────┬──────────────────────────────┐
│  品种列表  │        价格显示区              │
│  （分组）  │      [大数字价格]              │
│          │      涨跌 / 更新时间            │
│ 贵金属    ├──────────────────────────────┤
│  黄金     │                              │
│  白银     │         AI 对话区              │
│ 国际商品  │   （气泡：用户右 / AI 左）       │
│  ...     │                              │
└──────────┴──────────────────────────────┘
```

- **左栏**：品种分组列表（可点击切换，选中态高亮）。
- **右上**：当前品种实时价格（大字号）。
- **右下**：AI 对话区。

## 5. 组件规范
- **品种项**：悬停轻微高亮，选中态背景 `#F0F1F3`。
- **价格**：大字号，涨红跌绿、平盘灰。
- **对话**：气泡式，用户靠右（浅灰底）、AI 靠左（白底描边）。
- **按钮**：黑色矩形、圆角小、白字，hover 微降透明。

## 6. 可用性
- 断网 / 数据源异常时，价格区显示明确提示，不崩溃、不卡死。
- 所有操作即时反馈，无需二次确认。
