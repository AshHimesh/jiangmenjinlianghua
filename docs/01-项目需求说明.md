# 江门金量化 · 项目需求说明

> 版本：v2.0 ｜ 更新日期：2026-09-11 ｜ 状态：已确认（含阶段 7-9 增强需求）

## 1. 项目概述
- **项目名称**：江门金量化
- **项目定位**：Windows 桌面「行情看板 + AI 对话 + 分析报告」极简工具
- **目标用户**：个人投资者（无需任何编程能力）
- **核心价值**：一个界面同时看多个市场的实时价格，用自然语言向 AI 提问，
  并**输出带图表的可复制分析报告**。

## 2. 核心功能（阶段 1-6，已完成）

### 2.1 行情看板
- **数据源**：新浪（免费源，主力）
- **品种清单**（14 个，分四组）：

  | 分组 | 品种 |
  | --- | --- |
  | 贵金属 | 现货黄金、现货白银 |
  | 国际商品/指数 | 铜、WTI原油、纳斯达克100、标普500、美元指数 |
  | 国内商品期货 | 螺纹钢、焦煤、甲醇、乙二醇、纯碱 |
  | 国内指数 | 科创50、上证指数 |

- **交互**：点击品种 → 显示该品种实时价格，1–3 秒自动刷新。
- **涨跌标识**：红涨绿跌（国内习惯）。
- **界面不显示 K 线**：用户自有看盘软件（**注意：生成的报告里可以有图，见 5.3**）。

### 2.2 AI 对话
- **定位**：行情解读 + 分析助手。
- **能力**：结合实时行情 + 多周期技术面回答提问。
- **流式输出**：逐字输出，思考过程像网页 AI 一样展示（可折叠 + 思考耗时）。
- **多轮对话**：保留上下文记忆。
- **用户配置**：选择服务商 + 填写自己的 API Key。

### 2.3 Skill 技能
- 加载 `skills/` 下的 **.txt / .md** 技能文件，默认全部激活。
- 激活的 skill **全文注入系统提示词**，AI 必须遵循其框架与输出格式。
- 内置两个默认技能：斐波那契短线入场专家、价格行为斐波那契专家。
- 支持用户在界面里勾选启停、导入自定义技能。

### 2.4 智能缓存
- 相似问题命中缓存 → 直接返回上次结果（快、省 API 费）。
- 新问题 → 真正调用 AI → 答完自动存入缓存。
- 缓存带时效（20 分钟）。

### 2.5 AI 工具调用（Agent 模式）
- AI 可按需主动读取数据：`get_kline` / `get_indicators` / `list_symbols`。
- 支持工具调用的模型自动启用；不支持的模型自动降级，用户无感知。

## 3. 非功能需求
- **平台**：Windows
- **运行形态**：独立桌面窗口（双击打开）
- **部署**：打包后用户**无需安装 Python**
- **账号**：无账号、无登录、无云端，纯本地软件
- **界面风格**：极简白色

## 4. 明确的非目标（不做）
- 主界面里的 K 线图（报告里可以有，见 5.3）
- 交易下单
- 多用户 / 云端同步
- 移动端

# 5. 增强需求（阶段 7-9，待开发）

## 5.1 金十数据接入（阶段 7）

### 5.1.1 接入方式
- 通过**标准 MCP 协议**接入金十数据财经服务（`https://mcp.jin10.com/mcp`）。
- 流程：`initialize` → `notifications/initialized` → `tools/list` / `resources/list` → `tools/call`。
- 协议版本：`2025-11-25`。
- 结果读取优先用 `result.structuredContent`，`result.content` 仅作可读文本补充。
- 分页统一：请求 `cursor`，响应 `data.next_cursor` / `data.has_more`。

### 5.1.2 提供的能力
| 工具 | 作用 |
| --- | --- |
| `get_quote({code})` | 指定品种实时行情 |
| `get_kline({code, time?, count?})` | 指定品种K线 |
| `list_flash({cursor?})` / `search_flash({keyword})` | 快讯列表 / 搜索 |
| `list_news({cursor?})` / `search_news({keyword, cursor?})` / `get_news({id})` | 资讯列表 / 搜索 / 详情 |
| `list_calendar({})` | **财经日历** |
| 资源 `quote://codes` | 支持的报价品种代码表 |

### 5.1.3 设计约束（重点）
- **R7-A　API Key 由最终用户自己填写。**
  开发者的 token 只用于开发期联调，**绝不硬编码进程序**；
  交付版本里金十功能默认关闭，须用户到 ⚙ 自行填入自己的金十 API Key 才能启用。
- **R7-B　金十来源的数据必须在界面上明确区分标注。**
  用户要能一眼看出「这条数据来自金十」还是「来自免费源」，
  包括但不限于：品种列表角标、数据来源标签、报告里的来源注明。
- **R7-C　金十调用有额度限制（每个用户每个工具每天 1500 次），禁止用于行情刷新循环。**
  只允许出现在 AI 工具调用（按需触发）路径里。
- **R7-D　财经日历是 skill 的必要支撑。**
  默认技能明确要求「非农、CPI、FOMC 等重大事件前平仓或减仓」，
  没有日历数据 AI 无法执行该条铁律。
- **R7-E　金十可作为备用兜底源**：新浪的现货金银/原油/铜取不到时，可用金十顶上（需遵守 R7-C 额度）。
  - **本期（阶段 7）不实现**（2026-09-18 决定）：行情看板的价格**恒来自免费源**，
    金十只出现在 AI 工具调用路径。理由：2 秒刷新一旦接上金十会瞬间打爆额度。
    因此界面右上角的来源标签固定为「新浪财经（免费源）」，品种列表角标只表示
    「金十也提供该品种」，不代表当前价格来自金十。
  - 若后续要实现兜底，必须同时具备：失败触发（非定时）+ 同品种冷却（≥60 秒）+ 额度余量闸门。

## 5.2 品种扩充（阶段 8）

### 5.2.1 浙商积存金（数据源已确定：金十）
- **需求**：加入浙商银行积存金相关分析。
- **数据现实（2026-09-18 阶段 7 实测更新）**：
  - ✅ **金十 MCP 直接提供「浙商积存金」报价，代码 `CZBJCJ`**，实测现价约 944 元/克。
    原先判定「银行买卖价无公开接口」的缺口，已由阶段 7 的金十接入补上。
  - ✅ 可获取：**上海金 Au99.99 基准价**（上金所）、上金所现货报价
  - ❌ 仍不可得：浙商银行自身的买卖点差（仅在银行 App 内）
- **方案**：以「**浙商积存金**」（金十 `CZBJCJ`）作为可分析品种，数据来源标注为金十；
  同时保留「上海金 Au99.99」作为上金所基准对照。界面与提示词中标注
  「金十报的是浙商积存金基准价，银行实际买卖价含点差」。
- **约束**：该品种数据来自金十，同样受 R7-C 额度限制，**只走 AI 按需查询**，不进行情刷新循环。

## 5.3 分析报告与图表（阶段 9）

### 5.3.1 报告可复制 / 可导出
- 每条 AI 回答提供**复制**能力。
- 支持**导出为文件**（Markdown 或自包含 HTML）到程序旁边的 `reports/` 目录。
- 报告头部自动附**元信息**：生成时间、品种、各周期数据时间戳、当前价格、启用的 skill、数据来源。
- 还可考虑「标准报告模式」：按 skill 的模板输出结构化报告卡片。

### 5.3.2 报告生成图表（本次新增的重点）
报告里要**自动生成一张K线图**，并标注：

| 标注项 | 说明 |
| --- | --- |
| **浪型** | 艾略特波浪计数（如 ①②③④⑤ / ABC），标注在对应K线位置 |
| **支撑位 / 压力位** | 水平线或区间带，注明来源（斐波那契位/前高前低/均线） |
| **止盈位 (TP1/TP2/TP3)** | 水平线 + 标注，对应 skill 的交易计划 |
| **止损位 (SL)** | 水平线红色标注 |

**设计要点**：
- 图表**只出现在生成的报告里**，主界面依然保持极简（原需求不变）。
- 浪型与价位由 **AI 判定**（这是 skill 的核心能力），
  程序负责把它**结构化后渲染成图** —— 因此 AI 需输出结构化的标注数据。
- 实现路径：新增一个 AI 工具（如 `render_analysis_chart`），
  接收 `symbol / period / waves / support / resistance / entry / stop_loss / take_profit`，
  用 matplotlib 绘制K线 + 标注，输出 PNG 供报告引用。

### 5.3.3 待确认项
- 导出格式：Markdown + PNG 文件夹 / 自包含 HTML（可浏览器打印成 PDF）/ 两者都要
- 图表周期：由 AI 选一个主周期？还是出多周期小图？
- 是否需要「一键生成完整研报」（自动跑完 skill 的七步流程并出图）
